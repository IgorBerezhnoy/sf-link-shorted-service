
# Link Shortener Service

Консольное приложение для сокращения URL, написанное на Java 21.

Приложение позволяет создавать короткие ссылки, ограничивать
количество переходов, управлять ссылками и сохранять состояние
между запусками.

## Технологии

- Java 21
- Maven
- JUnit 5
- Java Collections (HashMap)
- Java Properties
- Java Desktop API

## Возможности

- Генерация уникальных коротких кодов
- Создание пользователей с UUID
- Несколько ссылок у одного пользователя
- Переключение между пользователями
- Открытие исходного URL в браузере
- Ограничение количества переходов
- Автоматическая проверка срока действия (TTL)
- Изменение лимита и удаление ссылок владельцем
- Сохранение данных в файл
- Восстановление данных после перезапуска
- Настройки через application.properties

## Требования

- JDK 21
- Apache Maven

## Запуск

Из корня проекта выполните:

```bash
mvn clean compile
java -cp target/classes Main
```

## Консольные команды

| Команда | Назначение |
|---------|------------|
| `help` | Показать справку |
| `create` | Создать короткую ссылку |
| `open` | Открыть ссылку в браузере |
| `find` | Найти исходный URL |
| `user new` | Начать работу нового пользователя |
| `user current` | Показать UUID текущего пользователя |
| `user list` | Показать пользователей |
| `user switch <UUID>` | Переключиться на пользователя |
| `link delete <code>` | Удалить свою ссылку |
| `link limit <code> <number>` | Изменить лимит переходов |
| `exit` | Завершить приложение |

При создании ссылки пользователь вводит исходный URL
и допустимое количество переходов.

Если текущего пользователя ещё нет, при создании первой
ссылки автоматически генерируется UUID.

## Конфигурация

Настройки находятся в файле `application.properties`
в корне проекта.

Пример:

```properties
link.ttl.hours=24
link.max-clicks=1000
link.code-length=6
```

- `link.ttl.hours` — время жизни ссылки в часах.
- `link.max-clicks` — максимально разрешённый лимит переходов.
- `link.code-length` — длина короткого кода.

Пользователь выбирает лимит переходов для своей ссылки,
но не может превысить значение из конфигурации.

Время жизни ссылки задаётся только конфигурацией приложения.

## Сохранение данных

При завершении работы состояние сохраняется в файл:

`data/state.properties`

При следующем запуске пользователи и ссылки
восстанавливаются.

Сохраняются UUID, исходные URL, короткие коды,
лимиты, количество переходов и время истечения ссылок.

Просроченные ссылки при загрузке не восстанавливаются.

## Тестирование

Для запуска тестов:

```bash
mvn clean test
```

Для полной проверки проекта:

```bash
mvn clean verify
```

Проект содержит 23 автоматических теста на JUnit 5,
включая проверки бизнес-логики, конфигурации
и сохранения данных.
